# Changelog

## [0.2.0] - 2026-04-03

### Added
- 🔔 Sound effects support using terminal bells
- New `--sound` flag to enable sound effects
- New `--bell-only` flag (default sound mode)
- Sound effects for:
  - Rage meter buildup (rapid bells)
  - Explosion phase (crescendo of bells)
  - Fake error messages (error beeps)
  - Progress bars (success chimes)
  - Mic drop finale (dramatic bell sequence)
- Prepared infrastructure for future full audio support with `audio` feature flag

### Changed
- Updated README with sound effect documentation
- Updated Contributing section to mark sound effects as completed

## [0.1.0] - Initial Release

### Added
- Initial release with core functionality
- Dramatic terminal animations
- Project analysis and resignation letter generation
- Bloat directory detection and cleanup
- Support for Node.js, Rust, Python, and Go projects
